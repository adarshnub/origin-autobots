## Diagnosis and repairs

The failed trace repeatedly tries to place the caret near individual letters and repair mistaken deletions. The independent fixture does **not** show a general coordinate offset in the tested 1920×1080 desktop / 1440×810 observation setup. It does not establish correctness for every monitor, DPI, app or tiny text target.

- Prefer Find/Replace, keyboard selection and document navigation; avoid repeated approximate character clicks. Save a separate copy before editing when the original must be preserved.
- Check actual Windows cursor position after movement and before clicking; reject when it has not arrived within two physical pixels. Keep focus/layout/lease checks and STOP active while waiting.
- Optional local JSONL diagnostics record normalized click targets, requested/measured physical positions, rejections, outcomes, durations and estimated costs.
- Hide the composer during tasks to remove it from Alt+Tab; register global shortcuts once across Hide/Show.
- Ctrl+Shift+S opened Mouse Without Borders/Snipping Tool in LIVE-02. Add a visible File-menu fallback when a utility intercepts Save As. Utility settings were not changed.
- Accept the model's `Super_L` / `Super_R` Windows-key aliases; retain blocked security/owner shortcuts. Add accessible names to pilot buttons, including STOP.

The correct LIVE-02 file demonstrates improvement, not universal reliability. No claim of universal app support or prompt-injection immunity is made.
