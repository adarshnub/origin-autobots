# Developer portfolio sources

Updated 26 September 2026. The portfolio uses public information from [adarshnub on GitHub](https://github.com/adarshnub), public repository documentation, and selected source files. The owner supplied the current company name **Ant Venture.ai**, which supersedes the older LinkedIn employer reference. The existing education details came from the owner-supplied [LinkedIn profile](https://www.linkedin.com/in/adarsh-viswam-95161016b/).

The public GitHub profile and repository metadata were read using GitHub and its unauthenticated REST API. README content was read through the README API or raw.githubusercontent.com. No repositories were cloned or executed; no dependencies were installed. Repository capabilities below describe published source and documentation, not independently tested behavior or operational status.

## Curation and limits

- The gallery contains 22 selected entries with category filters, text search, technologies and direct repository links. It includes all six projects pinned on the public profile when researched.
- Empty repositories, basic practice projects, duplicate research/backend repositories and starter-only examples were omitted. For example, shared-code-editor's inspected main page was still the default Next.js starter; its repository description alone was not used to claim a completed collaborative editor.
- Food-Ordering-App explicitly reported unfinished cart screens/price updates; it was not included in this selection. The small JSON-driven React Native example was also omitted.
- The page links the complete public repository listing for additional work.
- No live demos, app tasks, browser checks, test suites, audits or performance measurements were run. The website production build is solely the artifact generation step for publication.
